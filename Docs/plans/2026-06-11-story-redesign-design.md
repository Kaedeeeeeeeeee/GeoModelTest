# 剧情重构设计：防災ミステリー（地球の声を聞く力）

> 设计日期：2026-06-11
> 范围：15 分钟教学线的剧情框架重写。**不增删知识点、不改 beat 顺序、不动玩法。**
> 语言策略：本文先用**中文**写定剧本（= zh-CN 底稿），定稿后再译成**日文（漢字+ふりがな ruby）**并填入三语本地化。

---

## 1. 问题诊断

当前剧情承载了完整的教材功能，但没有故事脉络，玩家通关后不知道"讲了什么"。病根不是"没有故事"，而是**挖了坑没填**：

- 开场（quest1.1 / 1.2）抛出三个钩子：①异变的地震 ②超能力「地球（ちきゅう）の声（こえ）を聞（き）く力（ちから）」 ③"这街地下有某种东西在动"。
- 中段（beat2–4）全是教学，**三个钩子一个都没回收**；超能力开场后再没用过。
- 结尾（beat4）直接跳到"你已是合格的地质调查员，写个报告吧"。

附带两个问题：

- **博士是复读机**：カエデ只负责出题讲解，没有自己的目的/秘密/情绪。
- **主人公没有动机**：除了"有点怕又有点兴奋"，他没有想保护的人、想解开的谜。每关之间缺少"所以接下来呢"的拉力。

## 2. 设计目标与约束

| 约束 | 内容 |
|---|---|
| 时长 | 15 分钟封顶 |
| 受众 | 中学生（日语，漢字+ふりがな） |
| 教学 | R7 教材地质单元，**11 道题、所有知识点全保留** |
| 结构 | 线性，beat 顺序不变 |
| 改动面 | 只改"框架台词" + 每题前后 1–2 句，把练习题**装裱成证据** |

**核心原则：不要在教学"之外"再加故事——那只会更长、更割裂。要把教学本身变成解谜的推进，让每个知识点成为解开同一个谜题的线索。**

## 3. 核心设计

### 3.1 一句话主题
地层是这座城市的"过去记录"；学会读地层（=「地球の声を聞く力」的真身），就能预见它的未来——并赶在下一次灾害前发出警告。

### 3.2 中心悬念（贯穿全程）
**「刚才那场地震，是结束，还是开始？」**

### 3.3 结尾的科学 payoff（全部用现有知识点，不加新知识）
beat4 对比三地点柱状图时，把线索拼成一条推理链：

> 火山灰鍵層向东倾斜 → 某处地层出现褶皱（仍受挤压）→ 这一带地下应力仍未释放 → 开场那场地震只是断层的一次滑动 → **主人公在地图上指认下一个最危险的地点**，博士把它写成"防灾警告"而非"作业报告"。

开场的地震钩子，到这里才回收。

### 3.4 三个核心技巧（反复使用）
1. **so-what**：每个知识点后加一句"所以呢"，把名词翻译成场景（泥岩→"这里曾是安静的深海海底"）。
2. **鍵層红线**：火山灰层在 beat3 作为知识点出现（凝灰岩=火山喷发），在 beat4 成为破案的关键证据（鍵層→倾斜）。前面教的，后面真用上。
3. **地震节拍**：开场大震（beat1）→ 中途轻颤（beat3 余震）→ 结尾预警下一次（beat4）。给紧迫感一个心跳。

### 3.5 角色弧线
- **カエデ博士**：从"出题机"变成有动机的人。她多年想读懂这座城市的地层做防灾，但地层被植被/建筑盖住、露头不足；**地震震裂地面、暴露新鲜露头，才让调查成为可能**（正好是 vegetation/outcrop 系统的剧情理由）。主人公的"力量"= 好奇心 + 肯一层层读 + 这扇窗口期。
- **主人公**：这是他自己的城市、自己的教室被震。动机 = 不想再发生、想保护同学。给他一个具体牵挂（「あの教室」）。

### 3.6 超能力落地为隐喻
「地球の声を聞く力」不是魔法，而是**"会读地层的人"都能拥有的能力**。结尾博士点破：把地层一层层读下去，谁都能听见。保留诗意钩子，又诚实于科学，主题升华。

## 4. 运行时结构（实现约束）

## 10. 前因后果·世界观补充（2026-06-11 第二轮，"设定悬空"反馈）

用户反馈：教学动机已清楚，但 premise 悬空——①地震后为何传送到实验室 ②博士为何抓着他教。基调选 **B 轻科幻研究所**：

- **G-Lab = 防災/地质研究所，配「转送装置（転送装置）」**。开场白光 = 装置在塌方瞬间把主角转出（救援），也是野外⇄实验室往返的方式（＝ ID 999 场景切换器，复用之前废弃的转送装置设定）。
- **装置局限**（只够研究所周围、一次一人、救不了整座城市）——堵住"既然能传送为何还怕灾害 / 为何不把大家都救走"的逻辑漏洞，把重心推向"预测"。
- **博士动机**：手不够 + 主角是本地人、有理由亲手读懂脚下土地 → 教他本身就是使命（呼应结尾"地球的声音谁都能听见"）。

落地：`quest1.2` 新增 5 行（l12–l16）+ 改写 l05（防災研究所），三语齐全，Beat1B 11→16 行。后四幕未动。引用键 140 个，三语 0 缺失。
