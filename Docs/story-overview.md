## Beat 1A · 昼休みの異変（教室）

*开场：午休教室突发地震，主人公被卷入，视野没入白光。*

- **ナレーション**：昼休みの教室。とつぜん、大きなゆれが教室をおそった。
- **主人公**：うわっ…！？　地震だ…！　みんな、机の下に！
- **ナレーション**：ゆれはどんどん強くなり、てんじょうがくずれ落ちる。視界が白い光に包まれた——。

## Beat 1B · G-Lab（醒来 → 招募）

*醒来于地质研究所 G-Lab；研究员 Kaede 招募，抛出『地下有什么在动』的钩子。【问题①：地层形成顺序】*

- **ナレーション**：目をさますと、そこは見たことのない白い研究室だった。
- **Dr.Kaede**：気がついた？　ここは大地を研究する施設「G-Lab」。わたしは研究員のカエデ。
- **Dr.Kaede**：さっきの地震で、君には特別な力が芽生えたみたい。地球の声を聞く力よ。
- **Dr.Kaede**：実はこの街の地下で、今も“何か”が動いている。その正体を、君の力で確かめたいの。
- **主人公**：地球の声、か……正直こわいけど、ちょっとワクワクする。
- **Dr.Kaede**：いっしょに大地のなぞを調べてほしいの。まずは基本のおさらいからね。
```
問題①   〔教材 p.124 / p.128 ①（流水のはたらきの順番）〕
Q（Dr.Kaede）: 山の岩石がけずられて、海や湖で地層になるまで。正しい順番はどれ？

  ✅正解  風化→ 侵食→ 運搬→ 堆積
  　　　  堆積→ 運搬→ 侵食→ 風化
  　　　  侵食→ 風化→ 堆積→ 運搬

  ▶ 正解フィードバック: せいかい！　もろくなって、けずられて、運ばれて、積もる。この順番が基本だよ。
```
- **Dr.Kaede**：いい調子！　じゃあ、さっそく野外に出てサンプルを集めてみよう。

## Beat 2 · 採集と岩石判定（野外）

*野外露頭采样＋显微镜判定岩石。【问题②③④：粒径/盐酸/硬度 → 泥岩·石灰岩·チャート】*

- **ナレーション**：野外の露頭。地震でわれた地面に、しま模様の地層が見えている。
- **ナレーション**：崖の地層は、何万年もの時間を、しましま模様に閉じこめていた。
- **Dr.Kaede**：ハンマーでサンプルを取ったら、顕微鏡で粒の大きさを見てみよう。
```
問題②   〔教材 p.124 / p.126 / p.128 ②（粒の大きさで岩石判定）〕
Q（Dr.Kaede）: このサンプル、粒がとても細かくて 0.06mm 以下。さわるとなめらか。これは何という岩石？

  ✅正解  泥岩
  　　　  砂岩
  　　　  れき岩

  ▶ 正解フィードバック: せいかい！　粒が細かいほど、河口から遠い深い海でたまるんだ。
```
```
問題③   〔教材 p.126 / p.128（うすい塩酸→石灰岩）〕
Q（Dr.Kaede）: 次のサンプルに、うすい塩酸をかけたら、あわ（二酸化炭素）が出たわ。この岩石は？

  ✅正解  石灰岩
  　　　  チャート
  　　　  凝灰岩

  ▶ 正解フィードバック: そのとおり。石灰岩は貝やサンゴなどが積もってできて、塩酸で二酸化炭素を出すよ。
```
```
問題④   〔教材 p.124 / p.126（くぎで傷つかない→チャート）〕
Q（Dr.Kaede）: もうひとつ。くぎでひっかいても傷がつかないほど、とてもかたい岩石は？

  ✅正解  チャート
  　　　  泥岩
  　　　  れき岩

  ▶ 正解フィードバック: 正解！　チャートは海の小さな生物の殻が積もってできた、とてもかたい岩石だよ。
```
- **Dr.Kaede**：ふふ、いい目をしてる。地質調査員の素質あり、ね。
- **主人公**：同じ“石”でも、こんなに違うんだ……！
- **Dr.Kaede**：完璧！　岩石の見分け方がわかってきたね。次は深いところを調べよう。

## Beat 3 · 柱状図と化石（钻塔）

*钻塔多深度取样得柱状図，发现化石。【问题⑤⑥⑦⑧⑨：示相/示準化石·地质年代·凝灰岩→火山】*

- **Dr.Kaede**：ドリルタワーで、深さごとにサンプルを取ろう。地層の重なりが「柱状図」でわかるよ。
- **主人公**：こんな大きな機械で掘るなんて……！
- **ナレーション**：深い層をほり進めると、岩の中から化石が見つかった。
- **主人公**：うわ、本物の化石だ……！　何千万年も前の生きものが、今、目の前に。
- **ナレーション**：ドリルが深く進むほど、足元から低い響きが伝わってくる気がした。
```
問題⑤   〔教材 p.125 / p.127（サンゴ＝あたたかく浅い海）〕
Q（Dr.Kaede）: サンゴの化石だ。この地層ができた当時は、どんな環境だったと考えられる？

  ✅正解  あたたかくて浅い海
  　　　  冷たくて深い海
  　　　  川と海が混じる場所

  ▶ 正解フィードバック: せいかい！　サンゴはあたたかくて浅い海にすむ。だから当時の環境がわかるんだ。
```
```
問題⑥   〔教材 p.122 / p.124（示相化石）〕
Q（Dr.Kaede）: サンゴのように、地層ができた当時の「環境」を教えてくれる化石を何という？

  ✅正解  示相化石
  　　　  示準化石

  ▶ 正解フィードバック: そのとおり。環境を示すのが示相化石。シジミなら川と海が混じる場所だよ。
```
```
問題⑦   〔教材 p.123 / p.125（アンモナイト＝中生代）〕
Q（Dr.Kaede）: 別の層からアンモナイトが出たよ。この地層ができたのはどの時代？

  ✅正解  中生代
  　　　  古生代
  　　　  新生代

  ▶ 正解フィードバック: 正解！　アンモナイトは中生代の示準化石。サンヨウチュウなら古生代だよ。
```
```
問題⑧   〔教材 p.122 / p.124（示準化石）〕
Q（Dr.Kaede）: アンモナイトのように、地層ができた「時代」を教えてくれる化石を何という？

  ✅正解  示準化石
  　　　  示相化石

  ▶ 正解フィードバック: そう。広い範囲にすみ、短い期間だけ栄えた生物が示準化石になるよ。
```
```
問題⑨   〔教材 p.127 / p.128（凝灰岩→火山の噴火）〕
Q（Dr.Kaede）: 柱状図の中に、火山灰がおし固まった「凝灰岩」の層があるね。当時、何があった？

  ✅正解  近くで火山の噴火があった
  　　　  大きな地震があった
  　　　  海がかれた

  ▶ 正解フィードバック: 正解！　凝灰岩の層は、その時代に火山の噴火があった証拠だよ。
```

## Beat 4 · 比較と報告（实验室）

*对比 A/B/C 柱状図＋しゅう曲。【问题⑩⑪：地层倾斜方向·褶曲】→ 结尾弹出 A/B/C 调查报告。*

- **Dr.Kaede**：最後は、A・B・C 三つの地点の柱状図をくらべよう。火山灰の層を目印（鍵層）にするといいよ。
```
問題⑩   〔教材 p.128 ④ レベルUP（地層の傾き）〕
Q（Dr.Kaede）: 同じ火山灰の層が、東の地点ほど深い位置にあったわ。地層はどの方位に向かって低くなって傾いている？

  ✅正解  東
  　　　  西
  　　　  北

  ▶ 正解フィードバック: せいかい！　同じ層が深くなる方向に、地層は傾いて低くなっているんだ。
```
```
問題⑪   〔教材 p.125 / p.128（しゅう曲）〕
Q（Dr.Kaede）: がけには、波のように曲がった地層も見えた。大きな力でおし曲げられた地層の曲がりを何という？

  ✅正解  しゅう曲
  　　　  断層
  　　　  整合

  ▶ 正解フィードバック: そのとおり。両側からおし縮められる力で、地層が曲がったものをしゅう曲というよ。
```

- **主人公**：地球の声……ほんの少しだけ、聞こえた気がするよ。
- **ナレーション**：今日の調査をまとめて、報告書をつくろう。
