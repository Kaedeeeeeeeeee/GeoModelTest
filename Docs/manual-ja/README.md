## 編集と再生成

本文、図、配置は `build_manual.py` にあります。元スクリーンショットは `assets/`、取得元は `assets/sources.txt` に記録しています。主要なスクリーンショットは全体を載せ、PDF 上の枠・矢印で実際の位置を示しています。最終送信ページのみ、最後の質問・入力欄・左右のボタン・フッターを含むページ下部を掲載しています。画像内の内容は書き換えていません。

Python パッケージ: reportlab、Pillow、fonttools。日本語フォント: Google Fonts の Noto Sans JP 可変 TrueType フォント。作成時は Codex 同梱 Python と既存の作業用フォントを使いました。別環境ではフォントを指定します。

```sh
python3 Docs/manual-ja/build_manual.py --font-source /path/to/NotoSansJP.ttf
pdftoppm -scale-to 1500 -png output/pdf/ジオクエスト_あそびかたガイド_日本語.pdf tmp/pdfs/manual-ja/page
```

フォントは本文の文字を含むサブセットにして PDF に埋め込みます。作業用フォント・画像プレビュー・抽出テキストは `tmp/pdfs/manual-ja/` に出力されます。

## 内容の根拠と範囲

2026-09-11 のローカル main の実装と、日本語 UI の既存確認用キャプチャに合わせています。

- `SceneSystem/StartMenuBootstrap.cs`: 「研究に参加」→コード入力→「コードを確認」。認証成功後に開始。
- `Controllers/FirstPersonController.cs`: WASD、マウス移動、Shift、Space。
- `MobileSystem/MobileControlsUI.cs` / `UISystem/InventoryUISystem.cs`: 左スティック、視点ドラッグ、「道具」「調べる」「使う」。モバイルの「調べる」が道具の主操作を呼び出す。
- `Tools/SceneSwitcherTool.cs`: フェーズシフターを選び、パソコンは左クリック / F、スマホ・タブレットは「調べる」で移動先の選択。動画収録時に実機操作で確認し、旧記載の「使う」を修正。
- `Tools/HammerTool.cs` / `SampleSystem/SampleCollector.cs`: 同じ場所を3回たたく。生成された石は別途 E /「調べる」で拾う。
- `DrillTowerSystem/DrillTowerTool.cs` および配置用コード: 選択で配置プレビュー、左クリック /「調べる」で設置、近くで F /「使う」、出現した試料を拾う。
- 調査報告画面と `Assets/StreamingAssets/Survey/`: アンケートを開き、次へ、最後に送信、受信完了を確認。

採取・掘削の絵は操作の模式図として明記しています。結果画面は全体を掲載し、点数は表示例と明記しています。確認用に記入した自由記述や参加コードは紙面に載せていません。クイズの正答は指定していません。表示例の進行率は説明順序を示すものではありません。参加コード入力画面の背景には旧タイトル表記が残っていますが、コード入力と確認の操作は同じです。

この PDF は操作ガイドです。研究説明・同意書、募集機関向けの運用フローは別資料です。「ゲーム＋アンケート約20分」に操作ガイドの確認時間を追加する見積もりはしていません。
