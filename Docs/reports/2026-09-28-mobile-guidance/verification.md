# 手机与平板操作引导

本次修改位于本地源码，尚未发布到 itch.io。Unity 版本为 6000.0.51f1。

## 之前已经实现的部分

9 月 25 日的 `2ca9079` 已经包含采样步骤引导、触屏专用文案，以及 PC／移动端道具菜单里的推荐工具高亮。因此并非只实现了 PC 版本。但当时发布后的在线验收只覆盖桌面浏览器，玩家在移动端进入道具菜单之前，缺少明确的入口提示。

## 本次修改

- 靠近 NPC 时，提示框内显示与右侧实际「調べる」按钮相同的图标、配色和文字，并提示点击右侧按钮。PC 保留 E 键提示。操作教学也使用同一图示。
- 到达采样地点且需要装备工具时，真实「道具」按钮出现轻微高亮，提示卡中也提供可点击的同款图标。点击卡片图标打开原有道具轮盘，推荐工具继续高亮；装备后切换到具体操作提示。不会自动装备、跳过解锁或推进任务。
- 移动端第一次真实点击尝试进入全屏，保留主动退出行为，删除旧版 iPad 自动退出全屏的逻辑。浏览器不支持或宿主拒绝时提供短暂提示。详见 [全屏实现与浏览器限制](../2026-09-28-mobile-fullscreen.md)。

## 验证

- Unity EditMode：76 项通过。
- Unity PlayMode：10 项界面和输入隔离测试通过，包括真实按钮图标复用、移动／PC 提示切换、教学图示和手机／平板尺寸截图。
- 实际 MainScene：完整采样验收通过，52 个检查点覆盖 PC 和虚拟按键的地质锤／钻塔操作、样本拾取、提示卡打开轮盘、推荐工具保留及装备后入口隐藏。
- 本地 WebGL 开发构建成功，输出为 `Build/RemediationWebGL/`。核对打包后的全屏脚本和 CSS 与当时源码逐字节一致；生产发布目录未替换。
- JavaScript：真机反馈后新增旧 Safari 操作指引覆盖，全屏、性能和问卷模板共 23 项全部通过，其中全屏专项 12 项。
- 中／日／英本地化同步、重复键及 `git diff --check` 通过。
- Ego Lite：使用当前 WebGL 模板与已有游戏构建验证首次触摸全屏、退出后不重入、竖屏遮罩保留；用加载实际全屏脚本的跨域夹具验证 iframe 允许／拒绝两种情况。属于桌面 Chromium 模拟，未宣称实体 Safari 或 Android Chrome 验收。

本地测试前备份项目专用存档与偏好设置，测试结束后已恢复并校验一致，临时备份已删除。未提交真实研究数据。测试日志位于 `Logs/mobile-guidance-20260928/`。

验收期间发现并修正了测试定位误判：装备后的控件已隐藏，验证应检查玩家实际点击的按钮的 `activeInHierarchy`，不能用按名称查找是否返回对象代替可见性。
