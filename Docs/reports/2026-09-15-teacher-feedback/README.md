# 老师反馈：教学、对话与道具交互

后续发布：已构建并上线 `2026.09.15-teacher-feedback`（itch.io `1980722`）。详见 [发布与线上验收](release/README.md)。下方验证记录对应发布前的编辑器检查。

## 已完成

- 操作说明改为四页，按电脑／触屏设备自动显示对应内容：移动、视角、跳跃与奔跑；NPC 黄色感叹号及靠近变蓝；工具选择、使用、收起和各菜单；蓝色引导线与露头采样。
- 游戏画面常驻操作说明入口。电脑显示 `H 操作説明`，H 可打开／关闭；触屏显示 `？ 操作説明`。帮助可叠加在对话和目的地窗口上，关闭后恢复原来的暂停状态。
- 第一次在实验室介绍后进入野外，待剧情结束后自动弹出野外说明。说明提示“有蓝色线就沿线前往调查点；没有则检查左上角任务，可能还需要与研究员交谈”。每轮游戏只提示一次。
- 有可推进任务的新对话时，NPC 头顶显示黄色 `!`。靠近后的变蓝及 E／触屏交谈沿用原有交互。
- 对话正文显示“次へ”，最后一页显示“話を終える”。下一段对话可用时提示继续交谈；无新对话时，每次交谈重复当前阶段的简短提醒。提醒不执行任务完成回调、不重发奖励，也不修改正文的已读记录。
- 轮盘选择手势结束后才接受新一次工具使用输入，防止同一次点击既选中又使用工具。场景切换器的取消按钮／Esc 会关闭目的地窗口并收起工具。
- Tab／触屏轮盘增加独立的“何も持たない／空手／Empty hands”项，选择后卸下工具；HUD 同步显示空手。
- 修正程序生成的钻车图标上下方向。车辆预制体与实际模型未修改。
- 补充露头的简明定义及地质锤三次敲击、拾取样本的操作。未改变采样资格规则与引导线任务逻辑。
- 新增文案包含日语、简体中文、英语，并同步 Resources 与编辑器侧的本地化文件。

## 验证

Unity 6000.0.51f1，macOS。

- PlayMode 22/22：TeacherFeedbackTests、FirstControlExperienceTests、ModalInputTests、VehicleToolTests。
- LocalizationDataTests EditMode 7/7。
- 覆盖选择手势隔离、空手、取消场景选择收起、帮助与目的地窗口嵌套、重复提醒、NPC 新对话标记、首次野外说明等待剧情且只显示一次，以及三语四页文本布局。
- 实际 Unity Game View 检查：电脑 1366×768、触屏说明 844×390。检查了四页教学、黄色感叹号、H 常驻提示、最后一句的结束提示、空手轮盘项与钻车图标。H、Tab、Space 使用原生键盘输入复核。
- 鼠标选择与取消通过 Input System 注入式 PlayMode 测试验证。本轮原生窗口工具的坐标点击返回 `noWindowsAvailable`；未将其记为通过的手动鼠标验收。
- 触屏截图使用编辑器的触屏说明模式，未连接实体手机。这次验证未构建或发布新的 WebGL 包。
- 测试前备份本机 PlayerPrefs 与持久化目录，结束后恢复并校验。日志与备份位于被忽略的 `Logs/teacher-feedback-20260915/`。

`verification.json` 列出本轮自动化测试结果。
