# 第一次相移器移动的手把手教学

2026-11-02。本地源码修改，尚未发布到 itch.io 和 geo-q.jp。Unity 版本为 6000.0.51f1。

## 为什么改

Testee 配信到 11/02 的统计中，进入野外的 8 人全部通关，未完成的 10 人有 9 人在此之前离开，其中 4 人停在“用相移器去野外”这一步。走过第一次的人后面明显变快：从任务开始到抵达的中位耗时依次为 52、19、16、11.5 秒（只含走过第一次的人，有幸存者偏差）。

所以目标是把第一次教会，而不是跳过这几步。之后的移动仍是同样的操作，玩家迟早要自己走。

## 改了什么

- **第 1 次（研究室 → 野外）：** 压暗画面，分 3 步带玩家操作真实控件。第 1 步说明工具用途和“之后会用很多次”。不会自动装备，也不会替玩家移动。
- **触屏：** 只留真实按钮可以点。
- **桌面：** 压暗层不拦截输入。
- **不困住玩家：** 在压暗的步骤停留 20 秒后恢复画面，换回原来的提示卡。
- **抵达野外：** 显示 6 秒确认提示「移動できたね！次からも同じ手順で移動できるよ。」，等首次野外说明关闭后才出现。
- **第 2 次（野外 → 研究室）：** 先只提示「さっきと同じ手順で…」，15 秒后恢复分步提示。
- **第 3 次起：** 先不显示卡片，轮盘里的推荐高亮保留，15 秒后恢复分步提示。

问卷、开场问答和任务顺序都没有变。

## 验证

- Unity EditMode：173 项全部通过。
- Unity PlayMode：89 项中 83 项通过，无失败。另外 6 项需要专门的环境变量才会运行，本次跳过。
- 真实场景检查见 [checks.txt](checks.txt)，覆盖桌面和触屏的完整流程、按钮开口的点击判定、20 秒恢复、后续移动的提示退出，以及教学文字在日英中三种语言下完整显示。

**没有验证：** WebGL 构建和实体手机。触屏流程是在编辑器里用虚拟按钮模拟的。
