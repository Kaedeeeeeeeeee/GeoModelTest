# 无人机与钻车恢复

已发布到 [itch.io](https://kaedeeeeeeeeee.itch.io/geo-model-geological-drilling-simulator)，版本 `2026.09.11-vehicles`，HTML5 build **1965829**。最终源码 `cb2b8e6`，构建提交 `5eb2420`，均已推送 GitHub 的 `codex/experiment-validity-foundation` 分支。线上 HTML 与 release.json 已核对一致。

道具轮盘恢复「調査用ドローン」和「ボーリング調査車」。新游戏及旧存档都会补齐这两件道具；原有进度保留。模型改为随 WebGL 打包的 Resources 资源，发布后也能加载。

手机操作：点击左侧「道具」，选中载具，将视线移到前方空地，点击「ここに置く」，然后点击「操作する」。左侧摇杆移动与转向；无人机右侧的「上昇／下降」控制高度；钻车的「採取する」从实际地层生成可收集岩芯。完成后点击「操作を終える」或「収める」。无人机操作者留在起飞处，重新选择无人机即可远程收回并再次放置。

放置按钮会在位置有效时启用，提示过近或未瞄准地面的情况。手机的背包、图鉴、道具入口移到进度栏下面，避免被遮挡。载具控制期间，人物和手持工具不会同时响应移动与使用输入；退出时恢复摄像机和人物状态。

钻车生成的岩芯会记录来源道具 `1101`；主线要求的钻塔采样仍按原有任务条件判定。

## 网页实际操作验证

本地 WebGL 在手机尺寸（844 × 390、iPhone 用户代理、真实触控事件）和电脑尺寸（1366 × 768、鼠标与键盘）的 Chromium 中均完成了选取、放置、接管、移动、退出和回收。手机还验证了飞远后的无人机回收，以及两件道具回收后的再次放置。钻车在实际野外场景生成了可见岩芯。

首轮手机检查发现道具轮盘与场景切换器仍请求锁定鼠标，导致浏览器报错；最终构建已针对触屏设备取消这两处请求。鼠标点在界面上时也不会同时触发场景放置。

最终线上版本也从头完成了手机触控流程：道具轮盘、场景切换、无人机放置/升高/飞行/退出/远程回收/再次放置，以及钻车放置/驾驶/实际采样/退出/回收/再次放置。此轮 JavaScript 页面错误为 0，未出现所检查的 C# 运行异常。线上包保留了日文横屏提示和直接开始的开场剧情。

下方前六张图片均来自已部署的 itch.io 游戏资源页面，最后一张来自本地电脑端。公开游戏页的「Run game」入口亦已加载到同一版本。测试使用真实 Unity WebGL；手机检查采用浏览器模拟，没有连接实体 iPhone。
