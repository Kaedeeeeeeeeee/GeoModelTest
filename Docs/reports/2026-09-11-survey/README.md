## 关联方式

邀请码发放记录 → participant_id → 游戏会话 / run_id → 问卷答案。

游戏认证后向后端申请限定用于本次通关问卷的随机凭证，24 小时有效。后端检查真实已上传的通关记录，将参与者、会话、游戏轮次、问卷版本写入凭证记录。网页提交时只传答案和凭证，不接收可修改的身份字段。数据库只保存凭证哈希；链接凭证进入网页后立即从地址栏移除。

同一参与者、同一轮游戏、同一问卷版本只保存一份答案；重试或同时点击不会覆盖第一份。跨玩家、跨游戏轮次、过期、已撤回的凭证会被拒绝。发放邀请码时应保存包含 participant_id 的研究者发放清单，以便对照邀请码；数据库不保存明文邀请码。

研究者可使用 `supabase/survey-export.sql` 导出问卷和同轮游戏测验汇总。一般操作日志通过 participant_id / session_id 查询；跨会话的测验统计通过 participant_id / run_id 查询。
