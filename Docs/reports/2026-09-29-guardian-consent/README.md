# 保护者同意（网页）上线 — 2026-09-29

正式版本 **`2026.09.29-guardian-consent`**，itch.io HTML5 构建 **`2034117`**。后端迁移 `20260929090000_open_play_guardian_consent.sql` 与新版 `research-participation` 已部署到 Sendai 项目。

## 流程

1. 打开游戏链接后，在 Unity 启动前先显示老师提供的「保護者同意」全文。游戏同时在后台下载。
2. 家长选择「同意します／同意しません」，勾选「はい」（是保护者或法定代理人），用键盘输入「保護者氏名」和「お子様の回答者ID」。「同意日」自动显示当天日期。
3. 选「同意しません」：显示感谢画面，不进入游戏，不向服务器发送任何数据。可以点「回答を選び直す」回到表单。
4. 同意后：隐藏家长页，出现游戏标题和原有的学生本人同意窗口（文字不变，仍每次进入标题时确认）。
5. 点 New Game 时，Unity 把家长回答和学生确认时间随匿名参加登录一起发送。服务器第一次登录时保存同意记录，之后不再改写。
6. 家长回答保存在该标签页的 `sessionStorage`：刷新、闪退恢复不会再问；关掉标签页重新打开时会再问一次。

## 实现要点

- 家长页文字与 `保護者同意.docx` 逐字一致（去掉空白、□、下划线后比对），在 `index.html` 中。改文字时必须同时修改 `guardian-consent.js` 的 `VERSION`，已同意的人会被重新询问。
- **Unity WebGL 会吞掉页面上的所有键盘输入。** 对照实验：在上一版（9/28）的页面插入输入框，Unity 就绪后按键，输入框保持空白。新页面在 `<head>` 中先于 Unity 注册捕获监听，家长填写期间按键不传给游戏。本次在本地和线上 itch.io 框架内都实测可以输入。
- 回答者ID：全角转半角、长音符和各种破折号转「-」、去掉空格，只允许英数字和 `.` `_` `-`。支持用链接参数 `?rid=` 或 `?respondent_id=` 预填（itch.io 嵌入是否传递参数未验证）。
- 手机竖屏时，家长页期间不显示「横向きで遊んでください」；提交后恢复横屏提示。
- 家长页内禁止双指缩放，避免缩放状态残留到游戏画面。正文字号 16px，输入框 17px。
- 服务器：`studies.requires_guardian_consent` 对 `geoquest-open-play-2026-09` 开启。没有有效同意时返回 428／422，不建立游玩记录，也不接受日志上传或问卷。
- 家长姓名只保存在 `guardian_consents` 表（仅服务端可读）。研究导出只含 `respondent_id`、`consent_version`、`consent_recorded_at`，不含姓名。
- 新增导出命令：`consent-records`（同意记录，含姓名，需与研究数据分开保管）和 `completers`（给 Testee 的完成者回答者ID）。
