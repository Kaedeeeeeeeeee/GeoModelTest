# 电脑与手机的图解操作引导

版本：`2026.09.11-illustrated-controls`。Unity 6000.0.51f1，源码提交 `86b7c0a`。

## 电脑

四组键帽和鼠标图示对应四项操作：WASD 移动、移动鼠标观察、按画面提示的 E / F 互动、Tab 打开道具后点击选择。使用日文短句，说明具体方向与按键。

![电脑引导](desktop-guide.png)

## 手机和平板

横屏手机示意图标出左下摇杆、右侧空白滑动区域、右侧“調べる / 使う”和左上“道具”。图中的编号、颜色与右侧说明对应。为完整显示操作动词，说明使用较大的两行文字区。

![触控引导](mobile-guide.png)

图示由 Unity UI 图形绘制，可随界面缩放，不需要大幅外部图片。图示不接收操作输入，确认按钮关闭引导后恢复角色操作。

已经看过旧版文字引导的存档，也会显示一次新版图示；确认后继续存档不重复显示。新游戏会重新显示。

## 验证

15 项 PlayMode 测试通过，覆盖引导暂停与恢复、完成状态、完整说明所需的高度、手机输入稍后创建、仓库禁用与退出、菜单和载具回归。见 [测试结果](playmode.xml)。

截图来自 Ego Lite 实际运行的 WebGL 构建。手机使用 844 × 390 横屏和触摸输入模拟，不代表物理手机验收。浏览器常规截图接口此前出现超时，使用同一页面的实际 Unity 画布导出 PNG。
