DESIGN PROCESS

剧情テキスト量の決め方（設計の考え方）

文献を先に網羅するのではなく、「読む速さ × 読む時間」から必要な文字数を逆算する推定ベースで設計しました。

1
中学1年生が 1分間に読める文字数の目安を、調査データから把握する。
2
ゲームが 剧情の読書に充てる時間（約 5〜7 分）と組み合わせる。
3
両者から、剧情に適した文字数を算出する。
4
その文字数に合わせて本文を調整し、選択題（問題演習）を組み込む。
※ 後から学術文献（J-STAGE 等）でも目安を裏づけ。詳細は調査レポート参照。

SCRIPT EXAMPLE

剧情テキストの例（漢字＋ふりがな）

難しい漢字にはふりがな（ルビ）を付け、中学1年生が読みやすいように。

ナレーション：目めをさますと、そこは見みたことのない白しろい研究室けんきゅうしつだった。
Dr.カエデ：気きがついた？　ここは大地だいちを研究けんきゅうする施設しせつ「G-Lab」。わたしは研究員けんきゅういんのカエデ。
Dr.カエデ：この街まちの地下ちかで、今いまも“何なにか”が動うごいている。その正体しょうたいを、君きみの力ちからで確たしかめたいの。

物語は「地球の声を聞く力」を軸に、調査を続ける動機づけを与える。

QUIZ EXAMPLE

選択題の例（教材の問題を会話に組み込む）

Q（Dr.カエデ）：サンゴの化石だ。この地層ができた当時は、どんな環境だったと考えられる？
あたたかくて浅い海
冷たくて深い海
川と海が混じる場所
▶ 正解フィードバック：「サンゴはあたたかく浅い海にすむ。だから当時の環境がわかるんだ」（＝示相化石）
教材出典：p.125 / p.127（示相化石・サンゴ）

採集・観察などの操作の直後に出題 → 体験と知識を結びつける形成的評価。

SUMMARY

まとめ

  • 15分で完結する流れ（1コマに収まる）。
  • 本文は読む速さから逆算（約1,742字）。
  • 漢字＋ふりがなで読みやすさを確保。
